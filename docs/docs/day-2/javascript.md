# JavaScript Fundamentals

## Variables

```js
const workshop = 'SOMNOG9';
let day = 2;

console.log(workshop, day);
```

## Functions

```js
function greet(name) {
  return `Welcome, ${name}`;
}

console.log(greet('Participant'));
```

## Arrays

```js
const topics = ['Git', 'HTML', 'CSS', 'JavaScript'];

topics.forEach((topic) => {
  console.log(topic);
});
```
