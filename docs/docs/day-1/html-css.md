# HTML & CSS Fundamentals

## Basic HTML Structure

```html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>SOMNOG9</title>
  </head>
  <body>
    <h1>Hello SOMNOG9</h1>
  </body>
</html>
```

## Add CSS

```css
body {
  font-family: Arial, sans-serif;
  margin: 40px;
}

h1 {
  color: #2aa8d8;
}
```
